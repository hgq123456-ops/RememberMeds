# 💊 记得要吃药 Remember Meds

适老化 PWA 服药提醒工具。超大字体，一键操作，专为老人设计。

## 功能

- 📋 **今日待服药** — 打开即看，按时间排列
- ✅ **一键标记** — 点"我吃过了"就完成，零学习成本
- 🔔 **语音播报** — 到点自动说"降压药，该吃了"（支持 Chrome）
- 🔊 **蜂鸣闹铃** — 所有浏览器通用，到点滴滴滴提醒
- 📸 **拍照识别** — 拍药盒替代文字，不识字也能认
- 📅 **历史记录** — 按天查看，吃了没吃一目了然
- 📱 **离线可用** — 数据只存手机本地，断网也能用
- 👨‍👩‍👧 **家人管理** — 子女设置药品，老人只管点按钮

## 安装方式

### 方式一：PWA 安装（推荐）

1. 手机 Chrome 打开 `https://hgq123456-ops.github.io/RememberMeds/`
2. 底部弹出「📲 添加到桌面」→ 点安装
3. 桌面出现独立图标，像普通 APP 一样使用

### 方式二：苹果手机

1. Safari 打开上述网址
2. 点分享按钮 →「添加到主屏幕」

### 方式三：APK 安装（华为等安卓手机）

1. 用 [PWABuilder](https://pwabuilder.com) 输入网址
2. 生成 Android APK
3. 微信发送 APK 文件 → 手机安装

## 技术

纯 HTML + CSS + JavaScript，无框架，无依赖，无服务器。数据仅存手机本地（localStorage + IndexedDB）。
