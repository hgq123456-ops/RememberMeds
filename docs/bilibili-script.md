# 记得要吃药 — B站视频大纲

## 视频信息

- **标题**：我给爸妈做了一个吃药提醒APP，零代码基础也能做 | PWA入门实战
- **时长**：8-12 分钟
- **风格**：实战教程 + 一点温情

---

## 脚本结构

### 一、开场（30秒）

> 我妈高血压，每天三种药，老是忘。App Store 搜一圈，全是广告，老人根本用不来。
> 我就想——能不能自己做一个？老人打开就看到药，点一下就完事。
> 就是它——「记得要吃药」。

*[画面：手机打开APP，展示主界面——大字体药品卡片，橙色脉冲提醒]*

### 二、设计思路（2分钟）

| 画面 | 讲述 |
|------|------|
| 对比图：常规APP vs 这个 | "市面上的服药APP……字小、弹窗多、老人看都看不清" |
| 设计稿 mockup | "我们就三个原则：字大（28px）、按钮大（60px）、一个按钮搞定" |
| 老人视角 vs 子女视角 | "老人只看到吃药按钮，添加和记录藏在设置里，子女来管" |
| 药品卡片四种状态 | "绿色已吃、橙色该吃、红色错过、灰色还没到" |

### 三、AI 编程（2分钟）

| 画面 | 讲述 |
|------|------|
| Claude Code 对话界面 | "整个项目我没有手写一行代码，全用 Claude Code 完成的" |
| 视觉伴侣 mockup 对比 | "设计阶段直接在浏览器里看手机效果图，三种布局来回比" |
| 需求讨论截图 | "一边聊一边改——老人不识字加拍照、按钮逻辑矛盾当场修" |
| 实施计划文档 | "定稿后自动生成 12 步计划，每一步都有完整代码" |

### 四、技术讲解（2分钟）

| 画面 | 讲述 |
|------|------|
| VS Code 里的 index.html | "就一个文件，纯 HTML+CSS+JS，不需要前端框架" |
| manifest.json | "PWA 配置，告诉手机'我是APP'" |
| service-worker.js | "离线缓存，断网也能用" |
| 语音播报代码 | "speechSynthesis 中文语音，外加蜂鸣兜底——华为浏览器也能响" |

### 五、发布上线（2分钟）

| 画面 | 讲述 |
|------|------|
| git push 到 GitHub | "代码推上去，免费" |
| GitHub Pages 设置 | "开启 Pages，获得 HTTPS 网址" |
| 手机 Chrome 打开 → 安装 | "PWA 直接装到桌面，跟APP一模一样" |
| PWABuilder → APK | "华为手机也能用——一键生成安装包" |

### 六、给爸妈用（1分钟）

*[画面：老人手机实拍，打开APP，看到药，点"我吃过了"]*

> 就这样——打开，看一眼，点一下。没了。

### 七、总结（30秒）

> 很多东西不一定要去买，自己做一个反而更贴心。
> 代码我开源在 GitHub 了，链接在简介里。
> 给爸妈做一个吧。
