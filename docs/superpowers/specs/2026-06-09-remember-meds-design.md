# 记得要吃药（Remember Meds）— 设计文档

> 适老化 PWA 服药提醒工具 · 2026-06-09

## 项目概述

纯 HTML + CSS + JS 单页面 PWA，帮助老人按时服药。超大字体、超大按钮、语音播报、药盒拍照识别。无需安装、无需注册、离线可用。

## 设计决策

| 决策点 | 选择 | 核心理由 |
|--------|------|----------|
| 布局 | 老人视角单页 + 子女管理页分离 | 老人只看待服药+吃药按钮，零干扰；子女通过 ⚙️ 进入管理 |
| 添加药品 | 完整表单 | 覆盖所有服药场景（药名/剂量/次数/时间/周期） |
| 药品识别 | 照片 + 大字混合 | 照片为主角，不识字也能认；大字药名双重保障 |
| 语音提醒 | 每 2 分钟重复 | 直到老人点击"我吃过了"才停止，确保不遗漏 |
| 历史记录 | 按天分组 | 符合老人"按天回忆"的思维习惯，不加统计避免焦虑 |

## 双视图架构

设计核心原则：**老人只看到一张页面——今日待服药 + 吃药按钮。添加药品和历史记录由子女操作。**

## 数据模型

```javascript
// 药品定义（存 localStorage）
Medication {
  id: string,              // UUID
  name: string,            // "降压药"
  photo: string | null,    // base64 照片（存 IndexedDB，localStorage 仅存引用 key）
  dosage: string,          // "1"
  unit: string,            // "片" | "粒" | "包"
  times: string[],         // ["08:00", "20:00"] — 每天的时间点
  timesPerDay: number,     // 2 — 冗余字段，方便显示
  dateStart: string,       // "2026-06-09" — 默认今天
  dateEnd: string | null,  // null 表示长期服用
  note: string,            // "饭后服用"
  createdAt: string,       // ISO
}

// 服药记录（存 localStorage）
Record {
  medId: string,
  medName: string,
  date: string,            // "2026-06-09"
  time: string,            // "08:00"
  status: "taken" | "missed",
  recordedAt: string,      // ISO — 实际点击时间
}
```

## 技术实现

### 文件清单

| 文件 | 角色 |
|------|------|
| `index.html` | 单页面应用，包含全部 HTML/CSS/JS |
| `manifest.json` | PWA 配置（名称、图标、主题色、全屏模式） |
| `service-worker.js` | 离线缓存 + 后台运行 |

### 关键技术点

| 能力 | 实现方式 |
|------|----------|
| 照片存储 | IndexedDB（localStorage 上限 ~5MB，照片存不下） |
| 数据存储 | localStorage（药品元数据 + 服药记录，不含照片） |
| 定时检查 | `setInterval` 每分钟检查是否有到时间的药 |
| 语音播报 | `speechSynthesis` API，中文语音，重复直到点击 |
| 拍照 | `<input type="file" capture="environment" accept="image/*">` |
| 后台保活 | Service Worker + `setInterval` 心跳 |
| 离线可用 | Service Worker 缓存 index.html + 静态资源 |
| PWA 安装 | `beforeinstallprompt` 事件 + manifest.json |
| 锁屏运行 | Service Worker `periodic-background-sync`（如支持）|

### 语音播报逻辑

```javascript
function speakMedication(med) {
  const msg = `${med.name}，该吃了，${med.dosage}${med.unit}`;
  const utterance = new SpeechSynthesisUtterance(msg);
  utterance.lang = 'zh-CN';
  utterance.rate = 0.8;  // 慢速，老人听得清
  speechSynthesis.speak(utterance);
}

// 每 2 分钟检查一次，未点击则重复播报
setInterval(() => {
  const pending = getCurrentDueMeds();
  pending.forEach(m => speakMedication(m));
}, 120000);
```

## 边界情况

- **空状态**：今日无药品时显示"今天没有需要吃的药 😊"
- **全部吃完**：所有药品已吃，今日待服药区显示"全部完成 ✅"
- **跨天处理**：每天凌晨自动重置所有药品为"待服"状态
- **照片失败**：拍照失败或未拍照时显示默认药品图标（💊 emoji）
- **语音失败**：浏览器不支持 speechSynthesis 时静默降级，仅视觉提示
- **存储满**：IndexedDB 满时提示清理旧照片，不影响核心数据
- **日期过期**：超过 dateEnd 的药品自动停止提醒，移入历史
